# ToolImport 1.1.1

只修 Godot 窗口的三个问题，其它不动。

Three fixes to the Godot window, nothing else.

## 修了什么 / What changed

1. **窗口打开是空的** —— 列表与详情面板加错了父节点（加到窗口而不是那一列），尺寸算成零。现在正常显示。
2. **窗口出现在左上角、标题栏在屏幕外，不能拖** —— `Window` 进树即显示，定位代码没跑；现在先隐藏，定好尺寸并居中后再显示。
3. **设置窗口初始尺寸装不下内容** —— 现在按内容给足尺寸，并同样居中。

## 布局 / Placement

主窗口取可用屏幕的 60% × 72%（下限 900×600，上限 1500×1000），然后居中。用比例而不是固定像素，
是因为不同机器上窗口坐标与物理像素不一定一一对应。

## 升级 / Upgrade

覆盖 `res://addons/tool_import/` 即可。
